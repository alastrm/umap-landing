# Page Sections and Copy — Russian

This is a starting copy deck, not permission to claim unverified functionality. Keep text concise and original. Minor editorial refinement is welcome if the meaning stays accurate.

## Brand and navigation

- Brand: `Umap`
- Navigation: `Возможности` → `#features`; `О сервисе` → `#about` only if that section actually exists.
- Header CTA: `Открыть карту` → configured real map URL.

Do not show dead anchors. If a section does not exist, do not include its navigation item.

## Hero

- Eyebrow (optional): `Umap — карта города`
- H1: `Город ближе, чем кажется`
- Supporting paragraph: `Находите места и организации, выбирайте маршруты и исследуйте город на одной карте.`
- CTA: `Открыть карту`

Hero should show the actual product UI, not a 2GIS-style 3D imitation.

## Copy rejection rules

Do not write unverified claims such as `миллионы пользователей`, `№1`, `по всему Казахстану`, `в режиме реального времени`, `точные пробки`, `лучший навигатор`, `бесплатное мобильное приложение`, `ИИ-помощник`, `работает без интернета`.
