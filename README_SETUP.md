# Лендинг Umap

Статическая страница на Next.js App Router и TypeScript. Лендинг открывается по маршруту `/` отдельного сайта.

## Локальный запуск

Подходит Node.js 20.19+, 22.13+ или 24+ и npm.

```sh
npm ci
npm run dev
```

Откройте [localhost:3000](http://localhost:3000).

## Проверки и сборка

```sh
npm run lint
npm run typecheck
npm run build
```

Сборка формирует `out/`. Опубликуйте содержимое этой папки на статическом хостинге.

## Ссылка на карту

По умолчанию все кнопки «Открыть карту» ведут на `https://umap.kz/`, где Umap предлагает выбрать город. Для другого адреса скопируйте `.env.example` в `.env.local` и задайте `NEXT_PUBLIC_MAP_URL`. На хостинге передайте переменную в окружение сборки.

Ссылки на Астану и Алматы открывают тот же адрес с параметром `city`.

Если лендинг займёт `https://umap.kz/`, задайте отдельный адрес приложения карты перед сборкой, иначе кнопки будут возвращать посетителя на лендинг.

## Структура

- `src/app/page.tsx` собирает первый экран, основные секции, завершающий призыв и футер.
- `src/app/product-sections.tsx` содержит сетку возможностей и демонстрации поиска, карточки организации и построенных маршрутов.
- `src/app/city-section.tsx` проецирует контур страны и координаты городов через `d3-geo` при статической сборке. В `src/app/data/kazakhstan.json` сохранена геометрия Казахстана из [Natural Earth 1:50m](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_50m_admin_0_countries.geojson). Координаты маркеров соответствуют центрам карты Umap после выбора города.
- `src/app/site-links.tsx` задаёт навигацию и общую ссылку на карту.
- `src/app/globals.css` содержит типографику, композицию и правила адаптации.
- `public/assets/` содержит исходные ассеты Umap и облегчённые WebP-версии. Два предоставленных скриншота построенных маршрутов сохранены в WebP с отдельными кадрами для мобильной вёрстки.
- `design-references/` содержит референсы 2ГИС. Они лежат вне папки публикации.

Перед публикацией подтвердите права на предоставленные логотипы Umap.
