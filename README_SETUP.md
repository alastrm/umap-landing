# Лендинг Umap

Статическая страница на Next.js App Router и TypeScript. Лендинг открывается по маршруту `/` отдельного сайта.

## Локальный запуск

Подходит Node.js 20.19+, 22.13+ или 24+ и npm.

```sh
npm ci
npm run dev
```

Откройте [localhost:3000](http://localhost:3000).

## Проверки и сборка

```sh
npm run lint
npm run typecheck
npm run build
```

Сборка формирует `out/`. Опубликуйте содержимое этой папки на статическом хостинге.

## Ссылка на карту

По умолчанию все кнопки «Открыть карту» ведут на `https://umap.kz/`, где Umap предлагает выбрать город. Для другого адреса скопируйте `.env.example` в `.env.local` и задайте `NEXT_PUBLIC_MAP_URL`. На хостинге передайте переменную в окружение сборки.

Ссылки на Астану и Алматы открывают тот же адрес с параметром `city`. Кнопка в сцене «Маршруты» использует параметры ссылки, которой делится само приложение Umap, и открывает выбранный способ передвижения.

Если лендинг займёт `https://umap.kz/`, задайте отдельный адрес приложения карты перед сборкой, иначе кнопки будут возвращать посетителя на лендинг.

## Структура

- `src/app/page.tsx` собирает первый экран, основные секции и футер.
- `src/app/hero-scenes.tsx` переключает три сцены. `src/app/route-preview.tsx` показывает реальный пример маршрута в сцене «Маршруты».
- `src/app/editorial-sections.tsx` содержит Bento, раздел для организаций и футер. `src/app/product-sections.tsx` сохраняет ряд интерактивных карточек возможностей.
- `src/app/landing-content.ts` содержит демонстрационные показатели Bento и ссылки на Umap Business и Umap Developers. Замените значения подтверждёнными данными, затем отключите `isDemo`.
- `src/app/city-section.tsx` проецирует геометрию и координаты городов через `d3-geo` при статической сборке. Контур Казахстана, соседние страны и водоёмы взяты из [Natural Earth 1:50m](https://github.com/nvkelso/natural-earth-vector/tree/v5.1.2/geojson).
- В `src/app/data/kazakhstan-detail.json` сохранены упрощённые для масштаба карты линии областей из набора [UNHCR / HDX, Казахстан, 2023](https://data.humdata.org/dataset/cod-ab-kaz). Источник набора — OpenStreetMap, условия использования указаны в [метаданных HDX](https://data.humdata.org/api/3/action/package_show?id=cod-ab-kaz). Координаты маркеров соответствуют центрам карты Umap после выбора города.
- `src/app/site-links.tsx` задаёт навигацию и общую ссылку на карту.
- `src/app/globals.css` содержит типографику, композицию и правила адаптации.
- `public/assets/` содержит исходные ассеты Umap и облегчённые WebP-версии. Файлы `umap-route-*-scene.webp` показывают фрагменты реальных маршрутов между Хан Шатыром и Mega Silk Way. Кадры для машины и автобуса взяты из предоставленных скриншотов, пеший маршрут и превью `umap-city-*.webp` сняты в Umap.
- `design-references/` содержит референсы 2ГИС. Они лежат вне папки публикации.

Перед публикацией подтвердите права на предоставленные логотипы Umap.
